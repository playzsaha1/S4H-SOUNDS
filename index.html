Data handling

Files are processed locally in the browser whenever possible. S4H-SOUNDS does not depend on third-party analytics, ad tracking, or external script providers. We do not create persistent profile data from uploaded media.

Export workflow

Generated output files are delivered as local download artifacts. Sensitive metadata is retained only for the session and is not transmitted to any remote endpoint without your explicit action.

Compliance

This interface is designed to respect local network restrictions, avoid unapproved domains, and maintain a lightweight, school-safe technical footprint using native browser APIs and bundled assets only.
